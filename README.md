A high-end, fully responsive landing page concept developed for a fictional financial institution ("Osborn S.A."). The application showcases exclusive credit card tiers, dynamic financial calculators, integrated interactive chat simulations, and custom branding assets built with modern web technologies.

## ✨ Features

- **Dynamic Credit Card Tiers:** Interactive showcase of exclusive credit card categories (Black Elite, Platinum Infinity) featuring custom graphics and styling.
- **Interactive Financial Calculators:** Real-time financial estimator tools allowing users to calculate rewards and simulation metrics dynamically.
- **Embedded Conversational Assistant ("Bia"):** Interactive simulated chat workflow integrated directly into the interface to assist users with financial services.
- **Modern Responsive Design:** Crafted with Tailwind CSS grids and flexbox layouts ensuring seamless scaling across mobile, tablet, and desktop viewports.

---

## 🏗️ System Architecture

Built as a Single Page Application (SPA) using React and Vite, emphasizing component modularity, clean state management with hooks (`useState`, `useEffect`), and optimized asset rendering.

---

## 🛠️ Technologies Used

- **React (TSX):** Component-based UI development with TypeScript support.
- **Vite:** Next-generation frontend build tool providing lightning-fast hot module replacement (HMR).
- **Tailwind CSS:** Utility-first CSS framework for rapid and scalable design implementations.
- **Lucide React:** Modern icon library for clean interface indicators.
